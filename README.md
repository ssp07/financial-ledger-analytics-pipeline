# Autonomous Financial Ledger Analytics Pipeline 

An enterprise-grade, highly adaptive data intelligence application that dynamically ingests, normalizes, and audits unknown business financial records or government state ledgers. Powered by an internal **Self-Mutating Cash Flow Intent Engine**, this pipeline translates conversational corporate strategy queries into pristine relational SQL requests on the fly while instantly identifying operational revenue leakages and net liquidity variances.

## 🚀 Core Infrastructure Capabilities
* **Dynamic Introspection Engine:** Decouples hardcoded schema dependencies; maps value metrics, categorical attributes, and chronological parameters across completely unknown corporate datasets automatically.
* **SQL Encapsulation Layer:** Structurally shields relational database workflows by wrapping all extracted database columns in absolute SQL identifiers, neutralizing dot-notation syntax errors or special character formatting crashes.
* **Self-Mutating Financial FAQs:** Autonomously rewrites its 15 internal financial accounting audit dropdown routes to align perfectly with the target column layout profile of any uploaded file on launch.
* **Fuzzy Parameter Mapping Matrix:** Intercepts and parses natural user prompts (e.g., "show allocations over 500 ordered by highest value") using regex value isolation targets, keeping workflows error-free.
* **Enterprise Risk Dashboard:** Features real-time Side-by-Side Distribution bar analytics and Peak Concentration arrays to isolate cost spending pools natively.

## 📦 System Architecture Setup
1. Mount your target accounting spreadsheet named exactly **`dataset.csv`** into the project's folder directory.
2. Install your backend dependencies matrix from your prompt:
```bash
pip install streamlit pandas numpy
```
3. Boot the analytics viewport live:
```bash
streamlit run app.py
```
